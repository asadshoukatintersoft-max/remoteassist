# RemoteAssist
Free screen-sharing + voice help app (view first, control only when the phone owner allows).

Build: push this folder to a GitHub repo (branch `main`). GitHub builds `RemoteAssist.apk` automatically
(Actions tab) and publishes it under Releases. Stable download link:
https://github.com/<you>/<repo>/releases/latest/download/RemoteAssist.apk

Settings you may want to change: `app/src/main/java/com/remoteassist/fyp/Config.kt`.
